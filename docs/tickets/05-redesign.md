# Ship minimal swipe feedback and replayable teaching

## Parent

#10

## What to build

Make left/right sorting self-explanatory without permanent text over the photo.

## Acceptance criteria

- [ ] Drag follows the finger and reveals feedback-only lower-corner trash/check wells, with restrained gradients or native translucent material and legible symbols.
- [ ] Threshold feedback is visual and haptic; release short/cancel/vertical drag does not decide; successful release uses the durable-save contract.
- [ ] Preserve button presets, Favorite and Undo, safe-area bounds, accessibility labels, larger-text usability and Reduce Motion. Retain iOS 17 support.
- [ ] First-photo tutorial explains marking, keeping, confirmation and saving; dismiss once and replay from Settings. Adapt instructions to preset and isolate test state.
- [ ] On-device screenshots cover tutorial, partial left/right drags, bright/dark images and Settings; visually inspect rather than merely generate them.
- [ ] Tests check actual outcomes and layout; update provisional red tests/labels to the agreed behavior, not arbitrary identifiers. Sync docs.
