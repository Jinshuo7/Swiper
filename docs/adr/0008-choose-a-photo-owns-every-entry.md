# Choose a photo owns every entry into sorting

Every sorting session begins on Choose a photo. The entry screen offers one action
that opens it, plus resuming the session already in progress. The two traversal
choices that used to have their own front-page buttons live inside Choose a photo:
Newest starts at the newest photo and walks toward older ones, and Random is the
Tumbler. "Recent" retires as a word in the product. "Tumbler" stays the domain
term for the randomised mode.

Three doors, Recent, choosing a photo and Tumbler, asked a person to choose a way of
walking the library before they had seen it, and two of them committed them to
that choice with a single tap. Choose a photo already answers the question the others
were guessing at, where to begin, because it shows the library grouped into months
with a jump menu; giving it the newest and the random start turns three decisions
into one screen that explains itself.

Alternatives rejected: keeping Recent on the entry screen, which is the same
session type as choosing the newest photo in the grid and so duplicates Start
Here's first cell; and a separate Tumbler button, because a randomised order is a
property of the walk rather than a place to begin, and it reads better as an
action next to Newest than as a peer of the whole screen.

Consequences: the entry screen can offer at most two prominent actions, which is
what makes it quiet; opening Choose a photo must not discard a resumable session, so
only choosing a photo replaces it; the deletion list is untouched either way,
because it belongs to the library rather than to a session; and the mode stays in
the persisted session so resuming a Tumbler session resumes the same order.
