# T-1.2  Version the persisted session schema

file: SwiperKit/SessionPersistence.swift, SwiperKitTests/SessionPersistenceTests.swift
spec: SPEC 5.2
blocked_by: T-0.1
done_when: an unreadable or future-version session file is distinguishable from "no session"

## Verbatim SPEC clause
> 5.2  Persistence stores stable PhotoKit local identifiers only, never images.

## Required change
`FileSessionStore.read` is `try? Data(...)` then `try? JSONDecoder().decode(...)`, so ANY
decode failure silently becomes `nil` — indistinguishable from "the user has no session".
The next schema change would silently discard every user's resumable session.

Add `schemaVersion: Int` to `PersistedSession` (current = 1). On load:
  - version == current → decode as today
  - version < current  → migrate, or if no migration exists yet, refuse loudly
  - version > current  → refuse loudly
"Loudly" = a distinguishable outcome. Pick the simplest thing that is not `nil`: a
throwing load, or an explicit `.unreadable` result. Do not invent a UI for it — surfacing
is a later ticket.

## Tests
  - a session written by this version round-trips
  - a file with a higher `schemaVersion` is reported as unreadable, not as an absent session

## Do not
rename existing stored keys, or change `statistics.json` / `preferences.json`.

## Report
Both tests' real output, `git diff --stat`.
